# POV Café × فطن — ملفات الموقع الكاملة

الملفات جاهزة للرفع إلى جذر مستودع `Pov_Cafe` في GitHub Pages.

- `index.html`, `style.css`, `script.js`: الموقع ونموذج التقييم وصفحة العروض بعد الإرسال.
- `assets/pov-cup-original.png`: صورة كوب POV الأزرق والطائر، **محفوظة محليًا** (لا تعتمد على رابط صورة خارجي).
- `google-apps-script/Code.gs`: نسخة مرجعية للسكربت، وليست ملفًا يجب رفعه لتشغيل GitHub Pages.

## التقييمات

`script.js` يحتوي رابط Apps Script الذي قدمته. يرسل التقييم بـ `POST` باستخدام `no-cors`، لذا لا يستطيع المتصفح **إثبات نجاح حفظ الرد**. افحص ظهور صف جديد في تبويب **الردود** بالجدول. لا تغير نشر Apps Script إلا إذا لم تظهر الردود. يفضّل اختبار تقييم واحد من جهازك ثم التأكد منه.

## ملاحظة عن العروض

صفحة العروض تطابق الفكرة الظاهرة في مرجع ChatGPT Sites: ١٥ ريال لـ V60 مع شوكولاتة أو كوكيز، و١٠٪ خصم للماتشا أو المحصول الفاخر. **العروض مرئية كتجربة نموذجية**؛ تفعيلها ومدتها يحددها المقهى. رمز الإكمال يولّد في المتصفح، وهو مرجع للعرض وليس قسيمة معتمدة من نظام نقاط البيع.
