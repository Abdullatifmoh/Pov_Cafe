# POV Café × فطن — الإصدار المستقل

## إصلاح الكوب
الصورة الأصلية للكوب موجودة داخل `index.html` بشكل مدمج (Base64) وأيضًا في `assets/pov-cup-original.png`.
لذلك تظهر حتى إذا نُسي رفع مجلد assets أو استُخدم مسار مختلف.

## إصلاح ظهور صفحة العروض
تنسيق الصفحة والبرمجة موجودان داخل `index.html` لضمان عدم اختلاف الإصدارات القديمة في GitHub Pages.
بعد استكمال 3 تقييمات، وموافقات النموذج، والضغط على «أرسل تقييمي واكشف العروض»، يرسل الموقع الطلب ثم يظهر قسم العروض
(15 ريال و10٪) مع مرجع إكمال الاستبيان.

## رفع موقع GitHub
1. فك الضغط.
2. ارفع `index.html` في جذر مستودع `Pov_Cafe` واستبدله بالقديم.
3. الملفات الأخرى مرفقة للتعديل لاحقًا، لكن `index.html` يكفي وحده لتشغيل الواجهة الآن.
4. افتح الموقع مع تحديث قوي Ctrl+Shift+R.

## Google Sheets
رابط خدمة Apps Script مضمن في `index.html`.
يُرسل النموذج طلب POST بالـ JSON إلى الدالة `doPost` المنشورة.
**مهم**: `mode: no-cors` لا يسمح للمتصفح بالتأكد من قبول الخادم الطلب أو حفظه؛ ظهور العروض لا يثبت حفظ رد.
تحقق من تبويب «الردود» في Google Sheets بعد تجربة إرسال حقيقية.
كود `Code.gs` مرفق للمرجعية ولا يحتاج رفعه إلى GitHub Pages.

## ملاحظة العروض
هذه محاكاة توعوية، وليست إثباتًا أن مقهى POV قد فعّل خصمًا أو كوبًا مجانيًا.
