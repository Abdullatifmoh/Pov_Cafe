# POV Café × فطن

نسخة مستقلة قابلة للنشر على GitHub Pages، مستوحاة من المحتوى الظاهر في https://pov-cafe.boldtitan256.chatgpt.site/ وليست الشفرة المصدرية الأصلية له.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع `index.html` و`style.css` و`script.js` إلى جذر المستودع.
3. من Settings → Pages، اختر Deploy from a branch، ثم `main` و`/(root)` واحفظ.
4. رابطك يكون عادة `https://USERNAME.github.io/REPO/`.

## التقييمات
GitHub Pages خدمة استضافة ثابتة ولا توفر قاعدة بيانات أو خادمًا لتجميع ردود جميع الزوار. النسخة الحالية تحتفظ بالتقييمات محليًا في متصفح المشارك فقط. لجمع ردود فعلية من جميع الزوار، افتح `script.js` وضع رابط نموذج Formspree الخاص بك في المتغير `FORM_ENDPOINT`. بعد ذلك يمكن الاطلاع على الردود من لوحة Formspree. راجع سياسة الخصوصية للخدمة قبل استخدامها.

## رابط فطن
لتغييره، عدّل قيمة `href` للعنصر `id="fatinLink"` في `index.html`.
